# goods-shop

⚠️ **이 저장소는 public 입니다. GitHub Pages로 공개 배포되는 프론트엔드(HTML/CSS/JS) 파일만 커밋하세요.**

## 절대 커밋 금지

- Supabase `service_role` 키
- 토스페이먼츠 secret key
- Supabase Management API 토큰
- GitHub Personal Access Token
- 기타 `.env`, 비밀번호, API 시크릿

이런 값은 전부 **비공개 저장소** [goods-shop-project](https://github.com/tweety12288-spec/goods-shop-project) 또는 Supabase Edge Function secret / 환경변수로만 관리합니다.

커밋 전에 diff를 확인하고, 의심스러운 파일은 `.gitignore`에 추가한 뒤 커밋하세요.
